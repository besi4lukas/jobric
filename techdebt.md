# Tech Debt — Bugs & Gaps

Audit date: 2026-07-19 (branch `jobric_011`, at commit `054c870`).
Items #19-#21 added 2026-09-09 on `jobric_013` (Overview beta trim + AI
summary) — the audit date above still describes the original findings below.

Findings from a full read of the agents Worker, web app, D1 migrations, and CI.
Severity reflects impact on the product working end-to-end, not effort to fix.

## Summary

The ingestion pipeline and the UI were built as two disconnected halves. The
pipeline parses on metadata it doesn't actually have, and the dashboard displays
data it never fetches — so end-to-end, no real email currently reaches a user's
screen. Fix #1 and #2 first, since they determine whether the rest is even
observable.
